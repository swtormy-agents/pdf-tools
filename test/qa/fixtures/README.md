# QA regression fixtures

Synthetic adversarial inputs from the QA review of core 331a28a, used by
`test/qa-regression.test.mjs`. Generated with pikepdf, reportlab, Pillow and piexif; no
third-party or real user content. `LEAK-*` strings are canaries that must not appear in
any output. EXIF GPS values (N 12°34', W 98°76') are made up. Timestamps in the PDF Info
dictionaries are fixed at UTC.

Not committed (too large; generated in the tests or covered elsewhere): 2000- and
1001-page PDFs (`fx.plainPdf`), 1 GiB - 16 GiB object-stream / content-stream Flate bombs,
deep dict and long reference chains, PNG IDAT bomb and 7000x7000 RGBA PNG.
These files are test-only and are not part of the npm package (`files` in package.json).

## v2/ (QA review of aea0eb0)

Generated by the QA harness (`gen_variants.py`, pikepdf + Pillow + piexif), synthetic, same
`LEAK-*` canaries. Used by the `QA v2` tests in `test/qa-regression.test.mjs`:

- `exif-indirect-subtype.pdf`: JPEG with EXIF/GPS whose `/Subtype` is an indirect ref;
- `exif-hex-flate-dct.pdf`: `[/ASCIIHexDecode /FlateDecode /DCTDecode]` chain with EXIF;
- `exif-smask-nested-pattern.pdf`: EXIF JPEGs as SMask, in nested Form XObjects and a tiling Pattern;
- `exif-midscan-trailer.pdf`: APP1 after EOI / trailing bytes after the JPEG;
- `xmeta-alternates-smask.pdf`: image `/Alternates` with `/Metadata`, untyped XMP on an SMask;
- `af-form-privdata.pdf`: Form XObject with `/AF` and a private key to an untyped LEAK stream;
- `privkeys-indirect-s.pdf`: Launch action with indirect `/S` and `/Type` under a Font private key and page `/Group`;
- `inherited-pages-af.pdf`: `/AF` and `/Properties` JavaScript inherited from the `/Pages` node.

The v2 ObjStm bomb cases (1 GiB, 4 GiB) are built in the test (`helpers.mjs`), not committed.
